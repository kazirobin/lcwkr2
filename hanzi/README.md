5. STROKE VISUALIZATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Use this exact visual system:

BLACK:
Completed / previous strokes.

RED:
The CURRENT stroke being added.

LIGHT GRAY:
Future strokes that have not been written yet.

Therefore:

Step 1:
- Stroke 1 = RED
- All future strokes = LIGHT GRAY

Step 2:
- Stroke 1 = BLACK
- Stroke 2 = RED
- Future strokes = LIGHT GRAY

Step 3:
- Strokes 1–2 = BLACK
- Stroke 3 = RED
- Future strokes = LIGHT GRAY

Continue this pattern until the final step.

FINAL STEP:
- Entire character must be BLACK.
- No red stroke.
- No gray stroke.

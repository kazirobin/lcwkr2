# Project structure

A file-by-file map of the repository as it stands. For the *rules* behind this
layout (import direction, client/server boundary, how to add a feature), see
[`architecture.md`](architecture.md).

## Top level

```
lcwkr2/
├── src/                 All application code (see below).
├── public/              Static assets served as-is (/assets, /chinese-words.png, …).
├── hanzi/               Scratch notes (README only).
├── docs/                This documentation.
│   ├── architecture.md      Layering rules + how to extend.
│   └── project-structure.md This file.
├── .env                 Local secrets — gitignored, never commit.
├── .env.example         Documented list of required variables (no values).
├── AGENTS.md            Framework caveat for AI agents.
├── README.md

├── postcss.config.mjs   Tailwind v4 via @tailwindcss/postcss.

├── package.json
├── pnpm-workspace.yaml
└── package-lock.json / yarn.lock   Stray — pick one package manager.
```

## `src/` overview

```
src/
├── app/          Routes only — pages, layouts, API handlers. Nothing reusable lives here.
├── features/     One self-contained module per product domain.
├── i18n/         Language context + translation data (used everywhere).
├── components/
│   ├── ui/       Domain-agnostic primitives (Button, Field, Dialog, Table…).
│   └── layout/   App chrome (Nav, Footer, Breadcrumb, ThemeButton).
├── lib/          Framework-agnostic helpers (db.ts = Mongo connection).
└── providers/    React context providers mounted in the root layout (ThemeProvider).
```

## `src/features/<domain>/`

Every feature follows the same shape. Not all parts are present in every
feature (a data-only feature has no `server/`, etc.).

```
features/<domain>/
├── index.ts        Public surface. Import the feature THROUGH THIS.
│                   Client-safe only — never re-exports models/ or server/.
├── components/      React components for this domain.
├── data/            Static content / data for this domain.
├── models/          Mongoose schema(s) + models/index.ts.   SERVER ONLY.
├── server/          Data access + business rules, called by app/api handlers.  SERVER ONLY.
└── types.ts         Domain types.
```

## Path alias

`@/` maps to `src/`. Examples:

| import | resolves to |
|---|---|
| `@/i18n` | `src/i18n/index.ts` |
| `@/features/academy` | `src/features/academy/index.ts` |
| `@/features/academy/models` | `src/features/academy/models/index.ts` |
| `@/features/academy/server/students` | that file |
| `@/components/ui` | `src/components/ui/index.ts` |
| `@/components/layout/Nav` | that file |
| `@/lib/db` | `src/lib/db.ts` |
